## The Office-inspired Employee Manager Web App

This project is an Employee Management System designed to streamline the process of managing employee records. It allows users to perform CRUD (Create, Read, Update, Delete) operations on employee data with a user-friendly interface.

### Features ###
- **Add/Edit Employee**: Create new employees or update existing employee details using a form modal.
- **Delete Employee**: Remove an employee from the list with confirmation.
- **Search Employee**: Search employees by name using the search bar in the navbar.
- **Responsive Design**: The application is styled using Bootstrap to ensure a responsive and clean design.
- **Toast Notifications**: Provides feedback on actions (e.g., successful addition, deletion) using react-toastify.


### Technologies Used

- **Frontend**: React, TypeScript, Material-UI
- **State Management**: React hooks (useState, useEffect, useCallback, useMemo)
- **API Interaction**: Axios
- **Styling**: CSS, Bootstrap, Material-UI
- **Utilities**: react-toastify for notifications
